# SO-101 仿真前置检查

## 何时用

- 改过 `scene.xml` / `so101_new_calib.xml`（加物体、挪相机、调关节）
- 批量采集数据**之前**
- 训练**之前**（数据分布不对，训了也白训）
- 租算力**之前**（先本地确认数据没问题）

## 官方参数基准（LeRobot `so_follower`）

真机与仿真的关节顺序必须完全一致，否则数据全废。

| ID | 电机名 | 型号 | 官方归一化 |
|:--|:---|:---|:---|
| 1 | `shoulder_pan` | sts3215 | DEGREES |
| 2 | `shoulder_lift` | sts3215 | DEGREES |
| 3 | `elbow_flex` | sts3215 | DEGREES |
| 4 | `wrist_flex` | sts3215 | DEGREES |
| 5 | `wrist_roll` | sts3215 | DEGREES |
| 6 | `gripper` | sts3215 | **RANGE_0_100**（不是度） |

来源：`lerobot/robots/so_follower/so_follower.py:54-61`。

**两个推论**：
1. 官方默认 `use_degrees=True` → **公开数据集的 action 是度**，与我们的弧度接口差 57 倍
2. gripper 用 0–100，所以它的数值范围（约 60）比其他关节（约 170）小，单位检测阈值 >10 仍成立

## 三项前置条件

### 1. 方块可达性

方块必须在机械臂可达工作区内，否则 IK 解不出来、采出来的数据是垃圾。

**检查方法**：在工作区网格上跑 IK，统计成功率与位置误差。

**通过标准**：
- 目标区域（x∈[0.38,0.48], y∈[-0.10,0.10]）IK 成功率 **100%**
- 位置误差 **< 5 mm**
- 所有解的关节角在限位内

**不合格时**：缩小随机范围，或把方块往臂根方向挪。

### 2. 相机视野

方块必须在 `front_cam` 画面里，否则策略看不到目标，语言条件无从谈起。

**检查方法**：把方块放到网格点，渲染，用颜色阈值检测方块像素占比与位置。

**通过标准**：
- 每个网格点，目标方块像素占比 **> 0.3%**
- 方块中心落在画面**中央 80% 区域**（避免贴边）
- 三色方块互不遮挡

**不合格时**：调 `front_cam` 的 `pos` / `fovy`，或用自由相机扫参后反算（见 `docs/workflow.md`）。

### 3. 机械臂参数是否 SO-101

**检查方法**：读 MJCF，核对关节名、数量、顺序、限位、连杆长度。

**通过标准**：
- 关节数 6，顺序与上表一致
- `shoulder_pan` 限位 ≈ ±1.9199 rad（**109.8°**）
- `shoulder_lift` ≈ ±1.7453（100°）
- `elbow_flex` ≈ ±1.69（96.8°）
- `wrist_flex` ≈ ±1.6581（95°）
- `wrist_roll` ≈ -2.7438 ~ 2.8412（-157°~163°）
- `gripper` ≈ -0.1745 ~ 1.7453

**注意**：`so101_new_calib.xml` 的 elbow_flex 注释写着「5-degree calibration offset applied」，所以是 ±1.69 而不是理论 ±1.745。

## 检查命令

```bash
MUJOCO_GL=egl python3 scripts/preflight.py
```

输出三项 PASS/FAIL。**任何一项 FAIL 就不要往下走**。

## 每步 SOP

```
改场景/相机/参数
   → preflight.py（三项）
   → smoke_test.py（环境/渲染/采集/推理）
   → 小批量采样（2-3 条）人工看视频
   → 批量采集
   → smoke_test.py 复检
   → 训练
```

## 常见陷阱（社区 + 本项目实测）

| 陷阱 | 现象 | 来源 |
|:---|:---|:---|
| 单位混用 | 动作数值差 57 倍，关节打满限位但不报错 | 官方 use_degrees=True vs 我们的弧度接口 |
| 跳过 pre/post processor | 动作停在归一化空间（±0.5），看着像在动 | 本项目 B15 |
| BGR/RGB 反了 | 机械臂变青色、地面变棕色 | 本项目 B13 |
| 垂直抓取不可达 | 夹爪朝天翘，扣不住方块 | SO-101 腕部行程限制；isaka 项目自述 IK 不支持 |
| 相机背对机械臂 | 一片棕色/空桌面 | 本项目：臂朝 +x，相机放到了 -x |
| `n_action_steps=100` | 回放曲线每 100 步剧烈跳变 | 社区推荐 10 |
| torchcodec 加载失败 | 训练卡 0% | 社区与我们的 B2 一致 |
| 方块不会被带走 | 夹爪闭合了但物体留在原地 | `SimRobot` 不 `mj_step`，无接触力 |

## 通过之后

- 采集数据 → 立刻跑 `smoke_test.py` 复检
- 训练前确认 `--dataset.video_backend=pyav`、`--policy.n_action_steps=10`
- 云端训练前锁 `lerobot==0.4.4`（0.6.0 参数前缀变了）
