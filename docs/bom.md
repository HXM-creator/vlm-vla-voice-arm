## 二、三组容易混淆的参数

| 项 | 值 | 说明 |
|:---|:---|:---|
| **舵机电压** | 7.4 V（两臂相同） | 主臂**只能**用 7.4V，12V 反驱太重 |
| **齿轮比** | 从臂全 C001；主臂 C001+C044+C046 | 影响反驱手感 |
| **供电电压** | **5 V** | 官方 BOM 就是 5V，7.4V 舵机降额使用 |

买舵机看「电压 + 齿轮比」，买电源看「5V」。

## 四、为什么不用自研 MCU

| 项 | 官方转接板 | 自研 MCU |
|:---|:---|:---|
| 功能 | USB 转总线 | 相同 |
| 价格 | ¥54（2 块） | ¥50–150 |
| 开发 | 0 | 2–4 周 |
| 风险 | 社区验证 | 双 CDC 是已知深坑 |
| 增量价值 | — | 安全保护、硬件时间戳 |

**结论：传输用转接板，保护用 MCU 旁路，两者并存。**

## 七、购买时的四个确认点

| # | 确认什么 | 出错后果 |
|:--:|:---|:---|
| 1 | 舵机是 **7.4V** 版 | 主臂拖不动 |
| 2 | 齿轮比型号 C001 / C044 / C046 | 数量对不上，装不了 |
| 3 | 相机支持 `exposure_auto` 手动锁定 | 训练数据失效 |
| 4 | 转接板跳线拨到 **B 通道（USB）** | 插上没反应 |

相机验证：

```bash
v4l2-ctl --list-ctrls
# 必须能看到 exposure_auto 和 focus_auto
```

## 八、不买什么

| 物料 | 为什么 |
|:---|:---|
| 12V 电源 | 舵机是 7.4V |
| 深度相机（RealSense） | 策略只用 RGB，贵 30 倍 |
| 树莓派 | 跑不动 VLA |
| 自研 MCU 板 | v1 不需要 |
| 力传感器 | 先用 INA226 电流判断 |
