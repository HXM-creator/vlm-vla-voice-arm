## 关键决策

| 决策 | 结论 |
|:---|:---|
| VLM 职责 | 只做翻译 + 存在性确认 + 方位描述（方位不进 VLA） |
| 相机 | 录双路、训单路，腕部未到货用 front 占位 |
| 训练 | ACT 打底；SmolVLA 需 LoRA + 冻结视觉编码器 |
| 主控 | 优先 G474RET6（RAM 128 KB），G431 可用但紧 |
| 控制频率 | 总线 100 Hz、上报 50 Hz、定时器 1 kHz |
| 角度单位 | 硬件出度，`RealRobot` 转弧度并加越界断言 |

## 遇到的问题与解法

| 问题 | 原因 | 解法 |
|:---|:---|:---|
| 测试卡在 THINKING | 主线程与 VLM 线程抢同一指令队列 | 拆成 `_instruction_q` 与 `_vlm_in_q` |
| FEEDBACK 观察到不到 | `EXECUTING → FEEDBACK → IDLE` 在同一轮完成 | FEEDBACK 最少驻留 0.2 s |
| 动作全零 | 无 checkpoint，PolicyRunner 回退 | 属预期；用 `action_std` 判断是否真在推理 |
| 语言条件判定为 inconclusive | 无策略，动作全零 | 设计如此，不把「无法判断」写成「未生效」 |

## 补充：硬件选型定案

| 项 | 定案 |
|:---|:---|
| 机械臂 | SO-101，打印两套 |
| 舵机 | STS3215 **7.4V**，13 颗（C001×8 / C044×2 / C046×3） |
| 电源 | **5V/5A ×2**（每臂独立） |
| 转接板 | Waveshare ×2，¥54 |
| 相机 | **2 个** UVC 640×480，需支持手动曝光锁定 |
| 麦克风 | USB 会议全向麦 |
| MCU | **不自研**，v1 不需要 |
| 合计 | 约 **¥1985** |

清单见 [bom.md](../bom.md)。

### 关键判断

- **SO-101 vs SO-100**：官方 BOM 价格相同（¥1343），SO-101 装配更省事（不用拆齿轮）、走线更好、主臂反驱更轻
- **舵机电压**：两臂都是 7.4V；主臂**只能** 7.4V（12V 反驱太重）
- **供电电压**：5V，不是 7.4V（官方 BOM 就是这样，降额使用）
- **MCU 定位**：只做「PC 挂了也能生效」的事（急停、心跳卸力、过流），不替代转接板

### 队友方案的评估

| 观点 | 评价 |
|:---|:---|
| MCU 价值是「安全 + 可追溯」而非「更快」 | ✅ 正确 |
| 74HCT1G125 而非 74LVC1G125 | ✅ 正确（5V 时 LVC 的 VIH=3.5V） |
| 图像帧 33ms 误差 > 主从同步 6ms | ✅ 准确 |
| 三阶段 + 止损线 | ✅ 方法论正确 |
| 4 层板 / 13 模块 | ⚠️ 规模过大，2 层板够用 |
| SYNC 给相机做基准 | ❌ 普通 UVC 不支持外触发 |
