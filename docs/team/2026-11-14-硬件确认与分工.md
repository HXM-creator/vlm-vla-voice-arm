## 二、已确定的选型（请核对）

### 机械臂

| 项 | 定案 | 说明 |
|:---|:---|:---|
| 型号 | **SO-101** | 不是 SO-100。官方文档已把 SO-100 标记 deprecated |
| 结构 | 3D 打印，两套（主臂 + 从臂） | PLA+，0.4 喷嘴 / 0.2 层高 / 15% 填充 |
| 打印前 | **先打 Gauges 校准件** | 试配舵机后再打整臂 |

**SO-101 相比 SO-100 的改进**：不用拆齿轮、走线槽重新设计、主臂三种齿轮比混用（反驱更轻）。

**价格对比**：两者官方 BOM 都是 ¥1343.16，**零差价**。

| STS3215 7.4V **C044** | 1/191 | 2 | 主臂底座、肘部 |
| STS3215 7.4V **C046** | 1/147 | 3 | 主臂腕部、夹爪 |
| **合计** | | **13** | 单价 ¥98 |

**两个关键点：**

1. **两臂都是 7.4V**，主臂永远不能用 12V（要被人拖动，12V 阻力太大）

## 四、关于 MCU：建议先不做

### 结论

**v1 不需要自研 MCU。** 官方方案就是用两块 ¥27 的转接板，零固件。

### 你的方案里成立与不成立的部分

| 观点 | 评价 |
|:---|:---|
| MCU 价值是「安全 + 可追溯」，不是「更快」 | ✅ 完全正确 |
| 74HCT1G125 而非 74LVC1G125 | ✅ 正确，5V 时 LVC 的 VIH=3.5V，3.3V 驱不动 |
| 图像帧 33ms 误差 > 主从同步 6ms | ✅ 洞察准确 |
| 三阶段 + 止损线 | ✅ 方法论正确 |
| **画 4 层板** | ⚠️ 5V 逻辑 + 1Mbps 总线，**2 层板完全够** |
| **13 个模块** | ⚠️ 功能上只需要 5 个：供电、MCU、USB、两路总线 |
| **SYNC 给相机做基准** | ❌ 普通 UVC 相机不支持外触发，这个引脚做了没用 |
| **12/10 开始采数据** | ⚠️ 装配 13 颗 + 标定至少一周，太紧 |

### 建议路径

```
阶段 1（12 月）：买转接板，先把数据采起来
阶段 2（12 月中）：G431 最小系统 + 洞洞板，只验证三件事
                ① 心跳失效 → 卸力（测响应时间）
                ② 硬件时间戳（测抖动）
                ③ 双 CDC 能否稳定出两个 ttyACM
阶段 3（看阶段 2 结果）：
                ③ 失败 → 自研板改单 CDC，或直接用商用板
                ③ 成功且 ①② 有收益 → 再考虑打板
```

**花 ¥30 + 5 天，买一个「要不要走 3 周弯路」的判断依据。**

### 如果做，安全监督板的最小设计

| 功能 | 器件 | 价格 |
|:---|:---|---:|
| 心跳失效断电 | MCU 定时器 | — |
| 急停 | 按钮 + 继电器 | ¥15 |
| 过流保护 | INA226 | ¥15 |
| 状态灯 | RGB LED | ¥2 |
| 蜂鸣器 | 有源 | ¥2 |
| **合计** | | **约 ¥50** |

**关键：它不接管舵机总线。** 转接板照常工作，监督板只做保护——即使固件写崩，机械臂还能用。

## 六、分工边界

| 你 | 我 |
|:---|:---|
| 采购、打印、装配 | VLM 接入与指令解析 |
| 舵机 ID、波特率、中位 | VLA 训练与推理 |
| 主从标定、急停 | 状态机与语音链路 |
| 电气、线束、相机安装 | 数据采集脚本与数据集 |
| 硬件验收 | 仿真、训练、评估 |

**接口只有 `RobotInterface` 的 7 个方法：**

```python
connect(port) -> bool
disconnect()
get_joint_positions() -> ndarray(6,)   # 弧度
set_joint_positions(q)                 # 弧度
get_gripper_state() -> float
set_gripper(v)                         # 0~1
get_frames() -> {front, wrist}         # BGR
```

**约定：硬件层用「度」，我这边统一转弧度。转换只在 `RealRobot` 一处，你按度输出即可。**
